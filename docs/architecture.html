Salawat · Prière & Coran

Application web installable (PWA), sans publicité : horaires de prière, rappels d'Adhan, lecture et écoute du Coran, calendriers et outils. Hébergée sur une VPS Hostinger, en conteneurs Docker.

Vue 3 + Django 7 conteneurs salawat.dimatlas.com

Du navigateur à la base de données

Une requête HTTPS arrive sur le nginx de la VPS, qui la route par nom de domaine. Salawat tourne dans son propre projet Docker Compose, isolé du portail existant.

Parcours d'une requête

Navigateur / PWA→ nginx hôte (TLS)→ nginx frontend :8081→ gunicorn · Django→ Redis (cache) · PostgreSQL

Les horaires, la météo et les versets sont mis en cache dans Redis pour limiter les appels aux API externes. Les rappels d'Adhan sont planifiés par Celery beat, puis envoyés en Web Push par le worker des notifications.

Services Docker

Deux fichiers Compose se superposent : docker-compose.prod.yml décrit la stack, docker-compose.vps.yml ajoute ce qui est propre à cette VPS (frontend publié uniquement sur 127.0.0.1:8081).

Isolation

  • Projet Compose dimatimeprayer-prod : réseau, volumes et conteneurs propres.
  • Le portail dimatlas (projet voisin, port 8000) n'est jamais touché par un déploiement.
  • Seul le frontend est publié, en local : 127.0.0.1:8081.

Fiabilité

  • Healthchecks sur PostgreSQL et Redis ; le backend démarre quand les deux sont sains.
  • Redis en mode appendonly ; volumes nommés pour la base, Redis et les statiques.
  • Scripts de sauvegarde et de restauration PostgreSQL dans deploy/.

Mise à jour en production

Accès SSH temporaire par clé dédiée, retirée à la fin. Le fichier .env, l'audio et la base ne sont jamais écrasés.

1 · Clé SSH temporaire→ 2 · rsync du code→ 3 · docker compose up -d --build→ 4 · Contrôles HTTP→ 5 · Retrait de la clé

Ce qui est reconstruit

  • Le frontend Vue est compilé par Vite dans l'image Docker, puis servi par nginx.
  • Les migrations Django s'appliquent au redémarrage du backend.
  • Les utilisateurs de la PWA reçoivent la nouvelle version à leur prochaine ouverture.

Contrôles après déploiement

  • Réponse 200 sur le site et sur l'API des sourates.
  • Le portail voisin répond comme avant.
  • Endpoint /health/ du backend.
Établi à partir du dépôt du projet : fichiers Compose, requirements, package.json et routeur Vue.
